GUIA DEL PROJECTE DRAWINGS
==========================

Tasques pendents de la part Java
--------------------------------
1. Enviar la informació del front al back, per crear els objectes.

2. Completar el servei de dibuixos (DrawingService)
   Implementar la creació i actualització de dibuixos, assignar un nom aleatori si no se'n proporciona cap,
   consultar els dibuixos propis i els d'altres usuaris, cercar dibuixos per ID i permetre esborrar només
   els dibuixos de l'usuari propietari.

3. Completar el controlador de dibuixos (DrawingController)
   Implementar les rutes per obrir l'editor, desar dibuixos, consultar l'historial i esborrar dibuixos,
   comprovant l'autenticació de l'usuari amb HttpSession.

4. Crear les vistes de l'editor i de l'historial
   Afegir les plantilles editor.html i history.html, necessàries perquè funcionin les rutes corresponents.

5. Resoldre la deserialització de figures
   Definir com s'indica el tipus de figura al JSON perquè el servidor pugui reconstruir correctament les
   figures concretes (Circle, Square, Star, etc.) a partir de la classe abstracta GeometricFigure.

6. Implementar el JavaScript del canvas (script.js)
   Programar tot el fitxer script.js per controlar el canvas HTML5: dibuixar figures, afegir-les amb els
   botons, seleccionar-les, moure-les, esborrar-les, guardar automàticament amb AJAX al servidor i
   gestionar les accions de desfer/refer.
