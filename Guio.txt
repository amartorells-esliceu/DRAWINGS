GUIA DEL PROJECTE DRAWINGS
==========================

Tasques pendents de la part Java
--------------------------------

[ ] 1. Completar el desat i l'actualització de dibuixos a DrawingService
    - Si el nom és buit, generar-ne un per defecte.
    - Si és un dibuix nou, crear-lo amb un ID únic, l'usuari propietari i les figures rebudes.
    - Si ja existeix, comprovar que pertany a l'usuari autenticat abans d'actualitzar-lo.
    - Actualitzar el nom, les figures i la data de modificació, i desar el dibuix al repositori.

[ ] 2. Completar l'endpoint POST /drawings/save a DrawingController
    - Rebutjar les peticions sense sessió autenticada amb HTTP 401.
    - Passar l'ID, el nom, l'usuari de la sessió i les figures al servei.
    - Retornar el dibuix desat amb una resposta HTTP correcta.
    - Gestionar els errors de dades o de permisos sense donar el desat per correcte.

[ ] 3. Definir la deserialització de les figures rebudes en JSON
    - El servidor ha de poder distingir Circle, Square, Triangle, Star i Freehand.
    - Acordar el format del camp que identifica el tipus amb el JavaScript.
    - Comprovar que el JSON de cada figura es converteix al model Java corresponent.

[ ] 4. Afegir proves de la funcionalitat de dibuixos
    - Crear i actualitzar dibuixos; comprovar el nom per defecte i les figures desades.
    - Verificar que un usuari no pot modificar ni eliminar dibuixos d'un altre.
    - Provar les respostes de l'endpoint de desat amb sessió i sense.
    - Provar el processament de les diferents classes de figura.

Nota: la implementació del canvas i la resta de la lògica del navegador
corresponen al JavaScript i no formen part d'aquesta llista.
