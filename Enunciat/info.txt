DESAR LES FIGURES I ELS PUNTS COM A JSON
========================================

IDEA
----
El model Java manté les figures com una llista (List<GeometricFigure>).
En desar el dibuix, el repositori converteix la llista a JSON; en llegir-lo,
la converteix de nou a una llista. Els punts de cada figura queden inclosos
dins el mateix JSON.

CANVIS NECESSARIS
-----------------

1. Afegir una columna JSON a la taula drawings

   Afegeix la columna figures_json de tipus JSON. Aquesta columna guardarà
   totes les figures i els seus punts.

2. Adaptar DrawingRepoImpl.save

   Converteix drawing.getFigures() a JSON i inclou figures_json a les
   consultes INSERT i UPDATE.

3. Adaptar mapDrawing

   Llegeix figures_json i converteix-lo a List<GeometricFigure>. Si el camp
   és null, inicialitza una llista buida.

4. Deixar d'utilitzar les taules de figures

   Si el contingut del dibuix es guarda dins figures_json, les taules figures
   i figure_points ja no són necessàries per desar les figures i els punts.

IMPORTANT: TAULA EXISTENT
-------------------------
CREATE TABLE IF NOT EXISTS no modifica una taula que ja existeix. Per això,
afegir figures_json a schema.sql no basta si drawings ja està creada. En
aquest cas, afegeix la columna a MySQL amb una migració, per exemple:

    ALTER TABLE drawings ADD COLUMN figures_json JSON NULL;

Si encara no hi ha dades que vulguis conservar, també pots preparar l'esquema
en una base de dades nova amb la columna figures_json inclosa a CREATE TABLE.
